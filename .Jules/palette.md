## 2025-05-14 - Non-descriptive placeholder alt text in Profile READMEs
**Learning:** GitHub Profile README templates often include non-descriptive placeholders or non-English placeholders (e.g., "nama-kamu" which means "your name" in Indonesian) in image alt attributes. These are frequently overlooked by users but significantly degrade the experience for screen reader users.
**Action:** Always check all image alt attributes in profile READMEs for placeholder text or generic labels like "Header" and replace them with descriptive, English alternative text.
