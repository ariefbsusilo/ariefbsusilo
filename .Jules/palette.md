# Palette's Journal - Critical UX/Accessibility Learnings

This journal contains critical UX and accessibility learnings discovered during the course of improving this project.

## 2025-05-14 - Initial Accessibility Audit
**Learning:** README.md files often use placeholder Indonesian text in alt attributes (like "nama-kamu") or omit them entirely for badges, which degrades the experience for screen reader users.
**Action:** Always verify image alt text in profile READMEs and replace placeholders with descriptive English text.
