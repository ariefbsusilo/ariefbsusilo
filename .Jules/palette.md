## 2025-05-15 - [Accessibility: Placeholder alt text in README templates]
**Learning:** README templates (like those for GitHub profiles) often contain non-descriptive or placeholder `alt` attributes (e.g., "Header", "nama-kamu") that are frequently overlooked by developers. Replacing these with descriptive text significantly improves the experience for screen reader users.
**Action:** Always check README files for common image patterns (badges, stats cards, headers) and ensure their `alt` text is descriptive and localized correctly.
